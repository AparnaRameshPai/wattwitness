            Try to break it

            Here we attack our own sandbox on purpose. The safety check that normally screens the AI's code is switched off, so the sandbox alone has to hold. After every attack the server checks itself from the outside: a secret file on the server must be unchanged, and the sandbox engine must still be healthy.

            Autonomous AI hacker

            An AI model writes its own attack code, live, for five goals: escape, steal secrets, send data out, leave something behind, and slow the server down. All five run at once, each in its own sandbox.

            Bring your own attack

            Don't take our word for it. Write any Python you like (delete files, call the internet, hunt for keys, eat all the memory, leave something behind) and run it in a sandbox with the safety check switched off. Then the server checks itself from the outside.
